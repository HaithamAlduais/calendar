# تقويم هيثم

تطبيق تقويم محلي بواجهة تشبه Google Calendar، يولّد جدولك اليومي كاملًا بشكل فلكي
(مواقيت أم القرى للرياض) — وحدات من المغرب إلى المغرب بصفر فجوات، مع نظام القرآن
الثلاثي (تسميع/تثبيت/حفظ) وخطة التمرين الشهرية بالتقدّم المزدوج.

## التشغيل

```bash
python -m http.server 8080
```

ثم افتح: **http://localhost:8080**

(أو `npm start`، أو أي خادم ملفات ثابتة آخر على المنفذ 8080)

## المزامنة مع Google Calendar

طريقتان:

1. **ملف ‎.ics (بلا إعداد)** — من «الإعدادات» نزّل الملف، ثم في Google Calendar:
   الإعدادات ← استيراد وتصدير ← استيراد.
2. **مزامنة مباشرة** — أنشئ OAuth Client ID مرة واحدة من
   [Google Cloud Console](https://console.cloud.google.com/apis/credentials)
   (فعّل Calendar API، نوع Web application، وأضف `http://localhost:8080` في
   Authorized JavaScript origins)، والصقه في الإعدادات واضغط «اتصال».
   الدفع ذكي: يدرج الجديد ويحدّث المتغيّر ويتخطى المطابق — بلا تكرار أبدًا.

## ملاحظات

- **التقدّم مربوط بالإنجاز الفعلي**: اليوم الماضي الذي لم تعلّمه ✅ (أو تؤشّر
  بنوده) لا يتقدم بعده شيء — التسميع يعيد نفس الجزء، والحفظ نفس الربع،
  وأهداف التمرين تبقى للجلسة التالية. مسارا التسميع والحفظ مستقلان: تأشير
  البند ١ يقدّم التسميع وحده، والبند ٢ يقدّم الحفظ وحده. اليوم الحالي
  والمستقبل يُعرضان بافتراض الإنجاز (خطة مثالية من موضعك الحقيقي).
- **لوحة اليوم** في الشريط الجانبي: نسبة إنجاز اليوم، متتبع القرآن، قوتك
  الآن (أوزان الجلسة القادمة)، ساعات العمل/النوم/الراحة/الأسرة، وخانة
  «أضف مهمة إلى عمل اليوم» — المهام تصير بنود تأشير داخل بلوك العمل.

- **قائمة تأشير داخل كل حدث**: افتح أي حدث — كل بند مرقّم في وصفه يصير خانة
  قابلة للتأشير مع عدّاد إنجاز، وحالتها محفوظة. عند الدفع إلى Google أو تصدير
  ‎.ics تُرسل البنود المؤشَّرة بعلامة ✔ (لأن Google Calendar لا يدعم قوائم
  التأشير في الوصف).
- الجدول **يتمدد تلقائيًا شهرًا بشهر**: كتل ٢٨ يومًا (سبت←جمعة ×٤) من
  ١ أغسطس ٢٠٢٦، وعند دخول كتلة جديدة تُولَّد كاملة مع استمرار تقدّم التمرين
  والقرآن بلا انقطاع. وزر «تمديد الجدول أسبوعًا» متاح أيضًا.
- تعديلاتك على الأحداث تُحفَظ محليًا فوق المولَّد ولا تضيع.
- في رمضان: عدّل `isha` في `js/prayers.js` إلى مغرب + 120 دقيقة.
